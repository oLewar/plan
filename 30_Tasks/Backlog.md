# Tasks Backlog

Очередь задач, которые ещё не взяты в активную работу.

## Правила
- Каждая задача: цель, ожидаемый результат, критерий готовности.
- Приоритет по формуле эффективности из [[wiki/concepts/efficiency-metric]].
- Фокус-вопрос перед выбором следующего шага: «Какую одну вещь я могу сделать, чтобы благодаря этому всё остальное стало проще или не нужно?».

## Текущие кандидаты
- [ ] **Система оценки качества решений (Quality Scoring Framework)** — универсальный фреймворк с настраиваемыми профилями оценки по доменам. См. [[25_Projects/quality-scoring/Overview]]
- [ ] Свести все алгоритмы выбора решений в единый canon-документ.
- [ ] Ввести weekly lint-процедуру и шаблон отчёта.
- [ ] Сделать карту источников с оценкой качества данных.
