# Tasks Backlog

Очередь задач, которые ещё не взяты в активную работу.

## Правила
- Каждая задача: цель, ожидаемый результат, критерий готовности.
- Приоритет по формуле эффективности из [[wiki/concepts/efficiency-metric]].

- [ ] Свести все алгоритмы выбора решений в единый canon-документ.
- [ ] Ввести weekly lint-процедуру и шаблон отчёта.
- [ ] Сделать карту источников с оценкой качества данных.
