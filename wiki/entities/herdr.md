## Relevance

- Public **agent runtime / multiplexer**: server owns terminals; coding CLIs (including **Hermes Agent**) keep running when the TUI detaches.
- Adjacent to vault harness research: [[wiki/entities/deepseek]] replaces the *loop*; [[wiki/entities/cursor]] / pstack wraps *style*; [[wiki/entities/prime-intellect]] self-edits supplemental harness; Herdr wraps *place*.
- Direct Chappy surface: official `herdr integration install hermes` + `hermes --resume <id>`.

## What this vault currently knows

- Product is a Rust TUI + background server, not an Electron app and not a replacement for Claude Code / Codex / Hermes.
- Latest documented stable at ingest: **v0.8.2** (2026-08-19). Stars **33397** (GitHub API 2026-08-29).
- YC F26 announcement: runtime stays free/Apache; future work is connecting laptop / VPS / sandbox (homepage still redacts «where agents run while you sleep»).
- Plugins are ordinary unsandboxed executables discovered via GitHub topic `herdr-plugin`. Example cookbook (`ogulcancelik/herdr-plugin-examples`) is **not** official and **not** ingested.
- Community clients mentioned in the YC post (Raycast, Stream Deck, iOS) are third-party, not verified here.
