# Barbell strategy (tools & principles)

## Definition (working)

Держать **две крайности** и избегать «средней илистой зоны»:
1. **Frontier**: активно осваивать новейшие AI tools / feeds (X, day-zero product trials).
2. **Timeless**: читать верифицированное временем (100-year books, philosophy, math, physics; Amazon shareholder letter invariants; Morgan Housel *Same as Ever*).
3. Избегать полупроверенного «2-year-old book wisdom» как default authority.

## Business reading

- Build on **what never changes** (people want selection, low price, fast delivery; sleep/food/marriage rituals; hotels).
- Use AI as **accelerator**, not as replacement for durable value props.
- Long-lived businesses can ignore AI fashion and still exist — but will usually adopt it as leverage.

## Causal link

```
Timeless demand  →  durable strategy core
Frontier tools   →  speed / cost reduction on execution
Middle noise     →  false certainty, FOMO churn
```

- Совместимо с mission: сначала causal invariants, потом tool-leverage.
