# Vibe coding

## Definition (working)

Сборка софта преимущественно через LLM-агентов/чат (Claude Code, Codex, Lovable и т.п.) с минимальным ручным кодом: «описал — получил прототип».

## Claims from source

- Барьер входа упал: впечатляющие прототипы доступны без deep CS.
- Главные failure modes:
  1. Нет fundamentals → ломается на non-trivial change / scale / distributed systems.
  2. Откладывается contact with users.
- Профессиональный спрос не умирает (аналогии: фото vs живопись; DIY repair TV → больше заказов профи).
- «Вкус», архитектура, agency остаются дифференцирующими.

## Playbook (source)

1. Решить **личную** боль → быстрый ship.
2. Если цель — профессия: параллельно учить CS.
3. Держать no-ego update loop (новые tools/models weekly).

## Relation to vault mission

- Повышает скорость experiments ([[wiki/concepts/efficiency-metric|efficiency]]), но без causal/user check превращается в vanity prototypes.
- Связь с [[wiki/concepts/high-agency|high agency]]: tool не заменяет intention/mission.
- Связь с [[wiki/concepts/shokunin|shokunin]]: craftsmanship still compounds.
