# Causal analysis

## Purpose
Выявлять причинно-следственные связи между событиями так, чтобы решения были не реактивными, а системными.

## Working model
Для каждого важного события фиксируем:
- событие,
- предполагаемые причины,
- наблюдаемые эффекты,
- альтернативные объяснения,
- уровень уверенности.

## Confidence states
- `Hypothesis`
- `Confirmed`
- `Refuted`
- `Unknown`

## Minimal template
- Event:
- Candidate causes:
- Evidence:
- Counter-evidence:
- Downstream effects:
- Confidence:
- Next best question:
