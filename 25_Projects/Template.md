# Project Template

Используй этот шаблон для нового проекта.

## Структура
- `25_Projects/<project-slug>/Overview.md`
- `25_Projects/<project-slug>/Architecture.md`
- `25_Projects/<project-slug>/Tasks.md`
- `25_Projects/<project-slug>/Decisions.md`
- `25_Projects/<project-slug>/Links.md`

## Минимум для запуска
1. Определи цель и метрику эффективности.
2. Зафиксируй текущий контекст/ограничения.
3. Добавь backlog задач и ближайший спринт.
4. Заведи журнал решений (Decision Log).
