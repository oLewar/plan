# Kaizen

Кайзен-система для постоянного повышения эффективности: наблюдение → гипотеза → маленький эксперимент → измерение → стандартизация.

## Навигация
- [[25_Projects/Kaizen/Current|Current]] — текущий цикл и фокус недели
- [[25_Projects/Kaizen/Inbox|Inbox]] — сырые наблюдения, трения, идеи улучшений
- [[25_Projects/Kaizen/Backlog|Backlog]] — разобранные кандидаты на улучшения
- [[25_Projects/Kaizen/Experiments|Experiments]] — активные и завершённые эксперименты
- [[25_Projects/Kaizen/Metrics|Metrics]] — метрики эффективности

- [[25_Projects/Kaizen/Standards|Standards]] — закреплённые стандарты, чеклисты, правила
- [[25_Projects/Kaizen/Decisions|Decisions]] — решения по процессам

## Принцип

Главная метрика: **эффективность = ценность результата / затраты времени и риска**.

Каждое улучшение должно иметь:
- проблему;
- наблюдение/факты;
- гипотезу причины;
- малое изменение;
- метрику;
- timebox;
- решение: закрепить / изменить / откатить.

## Рабочий цикл

1. Capture — фиксировать трения в [[25_Projects/Kaizen/Inbox|Inbox]].
2. Clarify — превращать наблюдения в kaizen cards.
3. Prioritize — считать score: `Impact × Frequency × Confidence / Effort`.
4. Experiment — запускать 1–3 малых эксперимента.
5. Review — измерять результат.
6. Standardize — успешное превращать в [[25_Projects/Kaizen/Standards|Standards]], skill, script, cron или Kanban workflow.
