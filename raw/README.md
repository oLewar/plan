# Raw sources (`raw/`)

Этот каталог — **неизменяемая коллекция исходников**.

Правила:

- Добавлять новые источники можно.
- Изменять/переписывать содержимое существующих источников нельзя.
- Нормализация/конспект/анализ делается только в `wiki/`.
- Если источник дублируется или испорчен — добавлять отдельную заметку в `wiki/sources/`, а не редактировать оригинал.

## Folder taxonomy
- `raw/agent-dev/` — материалы по агентной разработке (основной фокус).
- `raw/finance/` — материалы по финансам/DeFi/blockchain.
- `raw/ml-research/` — базовые ML/исследовательские источники.
- `raw/general/` — прочие материалы, ожидающие точной тематической привязки.

Правило: файлы в `raw/*` не переписываются по содержимому, только сортируются по папкам.
