# Telegram добавил функции для ИИ-ботов: боты как полноценные участники переписок

![Иллюстрация](../../.hermes/image_cache/img_551f758b1dd3.jpg)

Telegram добавил функции, которые превращают ИИ-ботов в полноценных участников переписок 🤖💬

Теперь боты смогут отвечать от имени пользователя — для этого появилась функция «Автоматизация чатов». В настройках можно выбрать, какие диалоги ИИ сможет вести самостоятельно, а какие останутся только под контролем человека.

Ещё одна неожиданная функция: ботов можно вызывать в чат даже без предварительного добавления. Достаточно упомянуть ИИ-ассистента через тег — и он подключится к разговору, если у него активирован гостевой режим.

Кроме того, Telegram разрешил ботам взаимодействовать друг с другом. То есть ИИ теперь сможет не только отвечать людям, но и общаться с другими ИИ-агентами внутри чатов. Всё это, по задумке платформы, должно ускорить рабочие процессы и автоматизацию.

И наконец, ответы ботов стали «живыми»: сообщения теперь появляются постепенно, словно собеседник печатает текст в реальном времени — как в ChatGPT. Пользователям больше не придётся ждать, пока сгенерируется весь ответ целиком.
